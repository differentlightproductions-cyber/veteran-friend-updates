# Veteran's Friend — Android downloads

Free, independent veteran guide. Not affiliated with or endorsed by VA. This repository contains signed APK releases and update manifests only; the app source is maintained separately.

Download **VeteranFriend-local-model.apk** from [Releases](https://github.com/differentlightproductions-cyber/veteran-friend-updates/releases). Install the new version over the existing app to retain its local data. Android asks you to allow installation from your browser the first time; later updates can be checked in the app's Settings. Never uninstall the app to update it.

This is a testing APK, not a Google Play release or a clinically validated medical product. Read each release's known limitations. Reviewed guidance has source links and check dates; the app does not diagnose conditions, decide benefits or submit VA filings.

Do not post personal medical records, recovery phrases or account details publicly.
